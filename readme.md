Blind Shot 🎯🦆

Blind Shot is a fun, cartoon-style arena shooting game featuring a duck character. Players can enter the arena, fight opponents, survive challenges, and try to become the last player standing.

🎮 Game Features

- 🦆 Fun cartoon-style duck character.
- 🔫 Arena shooting gameplay.
- 🤖 AI bots to battle against.
- 🌐 Online multiplayer with host and join room options.
- 🏆 Survival challenges and elimination system.
- 👀 Spectator mode to watch the game after elimination.
- ⚡ Special perks and exciting final showdowns.
- 📱 Support for mobile and PC controls.

Can you survive the arena and become the ultimate champion?

Jump into Blind Shot and test your shooting skills! 🎯
